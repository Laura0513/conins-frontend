C) HORARIOS - EDICION DE BLOQUES (dia_ids)
   El frontend ahora envia un array de dias al editar un horario agrupado.
   
   - PATCH  /api/horarios/:id       -> Body: { dia_ids: [1, 3, 5], hora_inicio, hora_fin, ... }
   LOGICA: Comparar días actuales vs nuevos. Eliminar los quitados, actualizar los existentes, crear los nuevos.

D) CONSULTAS - REPORTES (NUEVO)
   Se implementó la página de Consultas con 3 pestañas. Se necesitan los endpoints para poblar las tablas.

   1. GET /api/consultas/carga-horaria
      Devuelve carga de trabajo por instructor.
      Formato esperado: [ { instructor_id, instructor_nombre, total_horas, fichas_count, competencias_count, estado: "Normal"|"Sobrecarga" } ]

   2. GET /api/consultas/horarios-ficha
      Devuelve horario semanal consolidado por ficha.
      Formato esperado: [ { ficha_numero, programa, lunes, martes, miercoles, jueves, viernes, sabado } ]
      (Los campos de días deben ser strings con el horario o "-" si está libre).

   3. GET /api/consultas/ocupacion-ambientes
      Devuelve porcentaje de uso de cada ambiente.
      Formato esperado: [ { ambiente_nombre, tipo, capacidad, horas_ocupadas, horas_totales, porcentaje } ]

E) ENCODING UTF-8
   Verificar collation de tablas. Si hay caracteres raros (tildes), ejecutar:
   ALTER TABLE programas CONVERT TO CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
